## Персональные данные

Твой Student ID пока не был указан. Поэтому чужие или выдуманные данные не добавлены в data, а результаты и скриншот не выданы за твои.

Открой папку patient-zero в IntelliJ/VS Code, установи JDK 17+ и выполни из этой папки:

```bash
java tools/Check.java
java -cp out tools/SelfTest.java
java tools/Prepare.java ТВОЙ_ID "ТВОЁ ИМЯ" "ТВОЯ ГРУППА"
```

ID впиши точно как в Moodle, включая начальные нули. Кавычки вокруг имени и группы оставь. Prepare создаст персональные файлы, запустит программу и заполнит персональные поля README.

После этого открой output/outbreak.html, проверь все девять зелёных отметок и сделай полный скриншот страницы под именем output/outbreak.png. Команда для повторного запуска программы: java -cp out Main. Для измерения времени: java -cp out Bench.

## GitHub

В архив включена настоящая локальная история Git: исходный проект, отдельный коммит на каждую из пяти миссий и оформление отчёта. Эти коммиты созданы Codex Assistant, что явно указано в README; после самостоятельного просмотра сделай собственные коммиты с реальными правками.

Создай пустой публичный репозиторий GitHub без автоматического README. Не выполняй git init повторно. Если в проводнике папка .git скрыта, это нормально: она уже лежит внутри проекта.

Настрой автора будущих коммитов, подставив свои данные:

```bash
git config user.name "ТВОЁ ИМЯ"
git config user.email "ТВОЙ EMAIL GITHUB"
git add .
git commit -m "Add personal data, reviewed report and outbreak screenshot"
git remote add origin https://github.com/ТВОЙ_ЛОГИН/patient-zero.git
git push -u origin main
```

Если GitHub не настроен, можно открыть существующий локальный репозиторий в GitHub Desktop и опубликовать его как public. Простая загрузка файлов через сайт не перенесёт локальную историю коммитов.

В Moodle сдаётся ссылка на публичный репозиторий до срока, указанного преподавателем. Защита: тест Moodle, 20 вопросов, 30 минут, 50 баллов; проект — ещё 50 баллов.
